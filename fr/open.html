How to set up local development
Step 1 — DNS (one-time, works for whole team)

Add a DNS A record in Cloudflare:

local.flyto2.com → A → 127.0.0.1

Now local.flyto2.com resolves to localhost for everyone.

Alternative — /etc/hosts (personal only) sudo nano /etc/hosts # Add: 127.0.0.1 local.flyto2.com
Optional — HTTPS for auto-detection brew install mkcert mkcert -install mkcert local.flyto2.com

With HTTPS, this page can automatically detect your local server and highlight it.

Pourquoi choisir Flyto2 Core ?

Construit pour les developpeurs qui valorisent la simplicite et le controle

Python 3.9+

Construit pour Python moderne avec annotations de type completes et support async. Code propre et lisible.

Multiplateforme

Fonctionne sur Windows, macOS et Linux sans modification. Un seul code, partout.

Fonctionne hors ligne

Pas d'internet requis apres l'installation. Vos donnees restent locales et privees.

Deploiement auto-heberge

Deployez Flyto2 Pro sur votre propre infrastructure avec Docker

Docker Pull
$ docker pull flytohub/flyto-pro:latest
$ docker run -d -p 8080:8080 flytohub/flyto-pro
docker-compose.yml 
version: '3.8'
services:
  flyto-pro:
    image: flytohub/flyto-pro:latest
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
    environment:
      - LICENSE_KEY=${LICENSE_KEY}

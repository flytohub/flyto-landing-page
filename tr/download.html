Neden Flyto2 Core'u Seçmelisiniz?

Basitlik ve kontrole değer veren geliştiriciler için tasarlandı

Python 3.9+

Tam tip ipuçları ve async desteği ile modern Python için tasarlandı. Temiz, okunabilir kod.

Çapraz Platform

Windows, macOS ve Linux'ta değişiklik yapmadan çalışır. Tek kod tabanı, her yerde.

Kendi Sunucunuzda Dağıtım

Docker ile Flyto2 Pro'yu kendi altyapınızda dağıtın

Docker Pull
$ docker pull flytohub/flyto-pro:latest
$ docker run -d -p 8080:8080 flytohub/flyto-pro
docker-compose.yml 
version: '3.8'
services:
  flyto-pro:
    image: flytohub/flyto-pro:latest
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
    environment:
      - LICENSE_KEY=${LICENSE_KEY}

Kendi Altyapınız

Herhangi bir bulut sağlayıcısında veya fiziksel sunucuda çalıştırın. Verileri siz kontrol edersiniz.

Otomatik Güncellemeler

Docker Watchtower desteği ile otomatik konteyner güncellemeleri.

Kurumsal Hazır

SSL/TLS ve kimlik doğrulama desteği ile üretim düzeyinde güvenlik.

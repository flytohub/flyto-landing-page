언어 팩

Flyto2에서 오프라인 사용을 위한 번역 파일 다운로드

  • Home
  • Language Packs

설치 방법

1. 언어 팩 파일 다운로드 (.json)
2. Flyto2 애플리케이션 열기
3. 설정 → 언어로 이동 Settings > Language > Import Language Pack
4. "언어 팩 가져오기"를 클릭하고 파일 선택

언어 팩이란?

Language packs are translation files that let you use the Flyto2 Desktop App in your preferred language. Each pack contains all the interface text — menus, buttons, messages, and tooltips — translated by native speakers and community contributors.

Flyto2 ships with English by default. By downloading a language pack, you can switch the entire application to another language in seconds. Language packs are lightweight JSON files, typically under 50KB, and do not affect app performance.

Help Us Translate

Flyto2's language packs are open source and community-driven. If you'd like to improve an existing translation or add a new language, we welcome your contribution. Our translation files are hosted on GitHub in the flyto-i18n repository, where you can fork, edit, and submit a pull request.

No coding experience is required to contribute translations. Each language file is a simple JSON document with key-value pairs. Just find the text you'd like to translate, add your translation, and submit. Our team reviews every contribution to ensure quality and consistency across all supported languages.

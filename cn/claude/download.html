Download Flyto Claude

Get the AI-powered automation assistant on your machine. Available for all major platforms.

Installation

Windows

winget install flyto.claude

Requires Windows 10 or later. Also available as a standalone installer.

macOS

brew install flyto-claude

Requires macOS 12 or later. Universal binary for Intel and Apple Silicon.

Linux

curl -fsSL https://flyto2.com/install.sh | sh

Supports Ubuntu 20.04+, Debian 11+, Fedora 36+, and other major distros.

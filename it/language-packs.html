Come Installare

1. Scarica il file del pacchetto lingua (.json)
2. Apri l'applicazione Flyto2
3. Vai a Impostazioni → Lingua Settings > Language > Import Language Pack
4. Clicca "Importa Pacchetto Lingua" e seleziona il file

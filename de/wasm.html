Flyto2 WebAssembly

Automatisierungs-Workflows direkt im Browser ausführen. Keine Installation erforderlich.

Erfahren Sie als Erster, wann das WebAssembly-Modul bereit ist.

Sie stehen auf der Liste! Wir benachrichtigen Sie per E-Mail, wenn es soweit ist.

Benötigen Sie jetzt Automatisierung? Probieren Sie Flyto2 Core (CLI)

Was kommt

Browser-native Automatisierung mit WebAssembly

Nahezu native Geschwindigkeit

WebAssembly läuft mit nahezu nativer Geschwindigkeit. Komplexe Workflows ohne Verzögerung ausführen.

Keine Installation

Keine Downloads, keine Einrichtung. Einfach das Modul importieren und loslegen.

Sandbox-Sicherheit

Läuft in der Browser-Sandbox. Kein Dateisystemzugriff, es sei denn, ausdrücklich gewährt.

Plattformübergreifend

Funktioniert in Chrome, Firefox, Safari und Edge. Ein Modul, alle Browser.

Instant Startup

No cold start delays. Load and execute workflows instantly in any browser tab.

250+ Module

Die gleichen leistungsstarken Module wie das CLI. String, Array, Daten und mehr.

Einfache Integration

Ein Vorschau, wie einfach es sein wird

script.js 
// Import the Flyto2 WASM module
import { Flyto } from '@flyto/wasm';

// Initialize
const flyto = await Flyto.init();

// Execute a workflow
const result = await flyto.execute('string.uppercase', {
  text: 'hello world'
});

console.log(result.data); // "HELLO WORLD"

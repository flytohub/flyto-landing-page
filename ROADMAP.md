# Roadmap

## P0 before production release

- Keep `robots.txt`, `sitemap.xml`, `llms.txt`, and `llms-full.txt` valid.
- Keep the ownership manifest and generated route/source reference current.
- Run `npm run typecheck` and `npm run build`.
- Include a GEO crawler report generated by `npm run geo:logs`.

## P1 before controlled production

- Keep trust, enterprise, airgap, open-source, compare, API-docs, and security
  route contracts synchronized with Docs and Warroom CE.
- Refresh multilingual metadata and keyword evidence from production search
  and crawler data without weakening the canonical/hreflang contract.
- Add browser smoke coverage for desktop and mobile public pages.

## P2

- Add public product-line comparison pages for Cloud, Security, Data,
  Zero-person Agent, and Big Data / Intelligence.
- Add structured FAQ blocks for pricing, enterprise, security, and automation.

Paket Bahasa

Unduh file terjemahan untuk penggunaan offline di Flyto2

  • Beranda
  • Paket Bahasa

Cara Menginstal

1. Unduh file paket bahasa (.json)
2. Buka aplikasi Flyto2
3. Pergi ke Pengaturan -> Bahasa Settings > Language > Import Language Pack
4. Klik "Impor Paket Bahasa" dan pilih file

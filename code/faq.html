Frequently asked questions

Everything you need to know about Warroom, zero-trust scanning, and how we keep your code safe.

General

What is Warroom?

Warroom is a security war room that aggregates every security dimension — SCA, SAST, secrets, containers, IaC, pentest, compliance — into one decision-grade view. Instead of juggling five different tools, you get a single dashboard with a unified score, priority actions, and one-click fixes.

How is Warroom different from Snyk or SonarQube?

We don't just report findings — we prove exploitability with browser-based verification and auto-fix in one click. Plus zero-trust: your code never leaves your machine. Other tools require you to upload your source code or connect your repo directly. We only see scan results, never your code.

What languages and frameworks do you support?

12 ecosystems: npm, PyPI, Cargo, Go, Maven, Composer, Gem, Mix, Gradle, Pub, Swift, and NuGet. The scanner supports any codebase — even if a package manager isn't in the list, the SAST, secrets, taint, and IaC analyzers still run.

Security & Zero Trust

Does my source code leave my machine?

Never. flyto-indexer runs locally on your machine. Only scan results — file counts, dependency lists, CVE IDs — are uploaded. No source code, no file contents, no secrets.

What data is uploaded?

Health score, dependency list, CVE matches, complexity metrics, and taint flow counts. All metadata — zero source code. You can inspect the exact payload with flyto-index export . --full before uploading.

Can I run in an air-gapped environment?

Yes. The Enterprise plan supports fully offline deployment with a local runner. The scanner itself works completely offline — you can even download vulnerability databases for air-gapped CVE matching.

How are API keys secured?

SHA-256 hashed before storage. The full key is shown once at creation and never stored in plain text. We follow the same pattern used by GitHub, Stripe, and other security-conscious platforms.

Technical

What is closed-loop verification?

Instead of just saying "you have CVE-2024-XXX", we dispatch a Playwright-based probe that sends real payloads to your target URL and proves whether the vulnerability is actually exploitable. Screenshot evidence is included in the finding, so you can see exactly what happened.

What is AutoFix?

Deterministic version bumps across 12 package ecosystems. We generate the exact diff, you review it, then one click to open a PR or download a .patch file. No AI hallucinations — just the correct version bump based on the CVE advisory.

How does scoring work?

Ratio-based: an org with 10,000 assets and 10 issues scores higher than one with 10 assets and 10 issues. The scale runs from 250 to 900, with grades A through F. This is similar to how BitSight and SecurityScorecard work, but applied to your own codebase.

Do you support CI/CD integration?

Yes. Use flyto-indexer in your pipeline: flyto-index scan . && flyto-index export . --full | curl -X POST -H "X-API-Key: ..." .../scan-upload. Works with GitHub Actions, GitLab CI, Jenkins, CircleCI, and any system that can run Python.

Pricing

Is there a free tier?

Yes. 3 repos, full scanning, health scoring, and the war room dashboard. Free forever, no credit card required.

Can I try Pro before paying?

14-day free trial, no credit card required. You get full access to all Pro features including AutoFix, closed-loop verification, and dynamic pentest probes.

How do you count repos?

Each connected GitHub or GitLab repository counts as one repo. Forks of the same repo count separately. Monorepos with multiple scan targets still count as one repo.

Can I switch plans?

Upgrade or downgrade anytime. Changes take effect immediately. If you downgrade mid-cycle, you'll receive a prorated credit for the remainder of your billing period.

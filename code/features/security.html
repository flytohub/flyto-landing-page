Find, verify, and prioritize vulnerabilities across every dimension. From taint-flow reachability to IaC misconfigurations, Warroom ranks what matters so you act on the right thing first.

Taint & Reachability Analysis

Know which vulnerabilities are actually reachable in your running code. The taint engine traces data from sources to sinks across your entire codebase, flagging unsanitized flows with file-and-line precision.

  • Source-to-sink tracking across function boundaries and modules
  • Identifies unsanitized flows with SQL_INJECTION, XSS, and path-traversal categories
  • Per-flow detail: exact file:line for source, sink, and every intermediate hop
  • Aggregate dashboard: 1,157 sources, 6,857 sinks, 7 unsanitized flows, 0% sanitization rate
  • Feeds into Pulse blast-radius scoring — reachable CVEs rank higher

IaC Scanning

Catch infrastructure misconfigurations before they reach production. Warroom scans Terraform, Kubernetes manifests, Docker Compose files, and Helm charts against industry benchmarks and custom policies.

  • Covers Terraform, Kubernetes, Docker Compose, CloudFormation, and Helm
  • Structured results: CHECK, FILE, RESOURCE, SEVERITY, and FRAMEWORK columns
  • Severity classification from LOW to CRITICAL with framework-specific context
  • Auto-detects framework from file patterns — no manual configuration needed
  • Misconfigurations feed into the war room’s cross-dimension correlation layer

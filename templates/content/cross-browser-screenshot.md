## How It Works

The Cross-Browser Screenshot template captures full-page screenshots of any URL across different browser engines — Chromium, Firefox, and WebKit. It renders your website in each browser and saves the screenshots side by side, so you can spot visual inconsistencies instantly.

Frontend developers and designers spend hours manually opening pages in different browsers. This template automates the entire process and delivers a visual comparison in seconds.

### Use Cases

- **Frontend QA** — Catch layout bugs, font rendering differences, and CSS issues across Chromium, Firefox, and Safari
- **Design review** — Share cross-browser screenshots with stakeholders to confirm visual consistency before launch
- **Regression testing** — Run after every deployment to ensure new changes don't break the UI in any browser
- **Client reporting** — Generate browser compatibility reports as part of web development deliverables

## Getting Started

1. **Import the Cross-Browser Screenshot** template from the Flyto2 marketplace
2. **Enter the URL** — provide the webpage you want to capture across browsers
3. **Run the template** — Flyto2 opens the page in each browser engine, takes full-page screenshots, and saves them for comparison

No browser installations or configuration needed. Flyto2 uses built-in browser engines to render every page accurately.

## How It Works

The GitHub Repo Stats Dashboard template automatically collects key metrics from any public GitHub repository — stars, forks, open issues, pull requests, and contributor activity. It visits the repository page, extracts the latest numbers, and saves them as structured data you can track over time.

Open source maintainers and developer advocates need visibility into how their projects are growing. This template builds that visibility without requiring GitHub API tokens or custom scripts.

### Use Cases

- **Open source maintainers** — Track star growth, fork count, and issue volume across your projects on a daily or weekly basis
- **Developer relations teams** — Monitor community engagement metrics for reporting and strategy planning
- **Tech investors** — Evaluate project health and traction by watching contributor activity and issue resolution speed
- **Competitive analysis** — Compare repository metrics across competing open source tools to understand market positioning

## Getting Started

1. **Import the GitHub Repo Stats Dashboard** from the Flyto2 template marketplace
2. **Add repository URLs** — enter one or more GitHub repository links to track
3. **Schedule and export** — run daily to build a historical dataset, then export as JSON or CSV for dashboards

No GitHub API key needed. The template reads publicly available data directly from repository pages.

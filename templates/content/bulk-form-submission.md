## How It Works

The Bulk Form Submission template automates filling and submitting web forms at scale. Feed it a spreadsheet of data, and Flyto2 will navigate to the target form, populate each field, and submit — row by row — until every entry is processed.

This eliminates hours of manual data entry for tasks like registering attendees, submitting applications, or entering records into web-based systems that lack a bulk import option.

### Use Cases

- **Event registration** — Submit attendee details for conferences, webinars, or training sessions from a single CSV file
- **Lead entry** — Bulk-add contact records into CRMs or marketing platforms that only offer manual form input
- **Government or compliance filings** — Automate repetitive form submissions for tax, licensing, or regulatory portals
- **Internal data entry** — Push records from spreadsheets into legacy web apps that don't support API integrations

## Getting Started

1. **Import the template** from the Flyto2 marketplace and open the workflow editor
2. **Map your data** — upload a CSV file and match columns to the form fields on your target page
3. **Run the batch** — Flyto2 fills and submits each form entry automatically, logging successes and failures

Perfect for anyone stuck doing repetitive data entry in web forms that don't offer bulk upload.

## How It Works

The IP Geolocation Lookup template takes a list of IP addresses and retrieves their geographic location data — country, city, region, ISP, and coordinates. It queries geolocation services through the browser, collects the results, and exports everything as structured JSON.

Network administrators, security analysts, and marketers all need to map IP addresses to physical locations. This template automates the lookup process for single IPs or bulk lists.

### Use Cases

- **Security investigations** — Trace suspicious login attempts or attack traffic back to their geographic origin
- **Access log analysis** — Map visitor IP addresses to countries and cities for traffic analytics
- **Compliance checks** — Verify that user traffic is originating from expected regions for geo-restricted services
- **Fraud detection** — Cross-reference transaction IP locations with billing addresses to flag mismatches

## Getting Started

1. **Import the IP Geolocation Lookup** from the Flyto2 template marketplace
2. **Enter IP addresses** — paste a single IP or upload a list for bulk processing
3. **Run and export** — Flyto2 queries each IP and returns location data including country, city, ISP, and coordinates

Process hundreds of IP addresses in minutes. No API keys or technical setup required — the template handles everything through the browser.

## How It Works

The Social Media Profile Scraper template collects public profile data from social media platforms — follower counts, bio information, post frequency, and engagement metrics. It visits each profile page, extracts the visible data, and exports everything in a structured format.

Marketers, recruiters, and researchers regularly need social media profile data for outreach, analysis, and reporting. This template replaces manual copy-pasting with automated, consistent data collection.

### Use Cases

- **Influencer marketing** — Evaluate potential influencer partners by collecting follower counts, engagement rates, and content themes at scale
- **Sales prospecting** — Gather public profile details for leads to personalize outreach and qualify prospects
- **Competitive intelligence** — Track competitor brand profiles to monitor follower growth and content strategy shifts
- **Academic research** — Collect public profile metadata for social media studies and demographic analysis

## Getting Started

1. **Import the Social Media Profile Scraper** from the Flyto2 template marketplace
2. **Enter profile URLs** — provide a list of public social media profile links to scrape
3. **Run and export** — Flyto2 visits each profile, extracts available data, and saves it as JSON or CSV

Only public data is collected. The template respects platform visibility settings and skips private profiles gracefully.

# 2026-07-18 i18n SEO Manifest Wiring

## Summary

Landing now reads SEO origin, hreflang, OpenGraph locale, and keyword additions
from `.seo/i18n-seo-manifest.json`, which is generated by
`npm run seo:sync` from `../flyto-i18n/dist/seo-manifest.json`.

The public locale prefixes remain unchanged (`zh`, `cn`, `pt`) to avoid
breaking indexed URLs. The SEO helper maps those public prefixes to manifest
locales (`zh-TW`, `zh-CN`, `pt-BR`) for hreflang output.

- `npm run audit:seo`

`next-intl` dynamic import cache warning still appears during Next build.
